# Bot commands

Open help, check bot status, and find support.

## User commands

- `/start`: Open start menu.
- `/help [module]`: Open help menu or view a module's guide.
- `/ping`: View latency and uptime.
- `/donate`: View donation information.
- `/feedback`: View owner support contact in private chat.

## Example

```
/help notes
```
