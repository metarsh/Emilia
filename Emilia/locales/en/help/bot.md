# Bot commands

Open help, check availability, and find support.

## User commands

- `/start`: Open the bot menu.
- `/build`: Explore Hanabi's custom development services and discuss your project.
- `/help [module]`: Open help menu.
- `/ping`: Show response time and uptime.
- `/donate`: Open donation information.
- `/feedback`: Find the owner's contact information in private.

## Example

```
/help notes
```
