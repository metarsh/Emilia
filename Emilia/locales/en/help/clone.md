# Clones

Want an Emilia bot under your own Telegram username? Create a bot with @BotFather, then register it here for hosting.

The main bot is the original Emilia bot where you manage your clones. A clone is the bot you created and own. Its BotFather token lets this hosting service run it.

Replace `<...>` with required input; `[...]` is optional. Do not type those brackets.

**Main bot commands in private:**

- `/clone <token>`: Register and start your bot using its BotFather token.
- `/mybots`: View your clones, restart them, or delete them.
- `/deleteclone`: Choose one of your clones to delete.

**Owner commands inside your clone:**

- `/setstartpic [image_url]`: Set the start picture using an image URL or a photo you reply to.
- `/broadcast <-all|-users|-chats>`: Reply to content to send it to both users and chats (`-all`), users only (`-users`), or chats only (`-chats`).
- `/clonestats`: View your clone's user and group totals.

**Examples:**

- View your hosted bots in the main bot's private chat:\
  `/mybots`
- Set your clone's start picture. Reply to a photo inside your clone:\
  `/setstartpic`
