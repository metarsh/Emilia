# Greeting examples

Compose welcome content first, then save it by reply.

## Welcome

Send `Welcome, {mention}, to {chatname}!` as a message, then reply:

```
/setwelcome
```

Enable welcomes:

```
/welcome on
```

## Photo welcome

Reply to a photo with your welcome text in its caption:

```
/setwelcome
```

## Goodbye

```
/setgoodbye Goodbye, {first}.
/goodbye on
```

## Reset

```
/resetwelcome
/resetgoodbye
```
