# Greeting examples

Examples for setting custom welcome and goodbye messages.

## Custom welcome

Send your message like `Welcome, {mention}, to {chatname}!` and reply to it:

```
/setwelcome
/welcome on
```

## Media welcome

Reply to a photo or video with caption:

```
/setwelcome
```

## Custom goodbye

```
/setgoodbye Goodbye, {first}.
/goodbye on
```

## Reset greetings

```
/resetwelcome
/resetgoodbye
```
