# Info

Look up user and group information or store personal bios.

## User commands

- `/id`: Show chat and sender IDs, or reply to a message.
- `/info [user]`: View detailed profile info by reply, username, or ID.
- `/ginfo <chat>`: Look up public group or channel info by ID or username.
- `/github <username>`: Look up a GitHub profile.
- `/setme <text>`: Save profile text up to 70 chars for self or replied user.
- `/me [user]`: View saved profile text.
- `/setbio <text>`: Save bio text up to 70 chars for self or replied user.
- `/bio [user]`: View saved bio text.

## Example

```
/setme I like anime.
/me
```
