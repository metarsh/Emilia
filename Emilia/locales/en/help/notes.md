# Notes

I can save text and media as notes so your group can find them again. Use them for answers, useful links, or anything you often need to share.

Notes are opened when someone asks for them; filters reply automatically. Notes appear in the group by default. Saving an existing name replaces that note.

A note is separate from the rules set with `/setrules` or the welcome set with `/setwelcome`.

Replace `<...>` with required input; `[...]` is optional. Do not type those brackets.

**User commands:**

- `/get <name>`: Open a saved note. You can also send `#name`.
- `/notes`: List the group's notes. Alias: `/saved`.

**Admin commands:**

- `/save <name> [text]`: Save a note. Add text after its name, or reply to the content you want to save.
- `/clear <name>`: Delete a note.
- `/privatenotes [on|off]`: View or change whether notes open in private chat.

**Owner commands:**

- `/clearall`: Delete every note after confirmation. This cannot be undone.

**Examples:**

- Save a short note:\
  `/save faq Ask an admin if you need help.`
- Open it:\
  `/get faq`
- Open it with a hashtag:\
  `#faq`

Use the guides below for media notes, access options, and formatting.
