# Stickers

Steal and clone stickers into custom packs, or download sticker files.

## User commands

- `/stickerid`: Get file ID of replied sticker.
- `/gifid`: Get file ID of replied GIF.
- `/getsticker`: Download replied static sticker as PNG.
- `/getvideo`: Download replied GIF video file.
- `/getvidsticker`: Download replied video sticker.
- `/kang [pack_number] [emoji]`: Add replied sticker, image, or URL to sticker pack.
- `/unkang`: Remove replied sticker from your pack. Alias: `/delsticker`.
- `/pkang [pack_title]`: Clone an entire sticker pack by reply. Alias: `/packkang`.

## Example

Reply to a sticker or image:

```
/kang 2 😀
```
