# Search tools

Search the web, look up definitions, and capture website previews.

## User commands

- `/google <query>`: Search Google. Alias: `/g`.
- `/wiki <query>`: Look up Wikipedia articles.
- `/define <word>`: Look up dictionary definitions.
- `/ud <word or phrase>`: Look up Urban Dictionary definitions.
- `/webss <url>`: Capture a webpage screenshot.

## Example

```
/webss https://example.com
```
