# Formatting

You can style the messages I save, add buttons, and include details such as a member's name.

Choose a guide below:
- Message styling: bold text, links, code, and buttons.
- Placeholders: names, mentions, chat details, and message options.

**Reading command instructions:**

- `<text>` means required input; `[text]` means optional input. Replace these with your own values without the brackets.
- In choices such as `on|off`, choose one word. Do not type the pipe.
- `[type ...]` means you can add more names, separated by spaces.
- Tags such as `{first}` are different: leave them exactly as written so I can fill them in.
- `emojipack:<>` is also literal. Keep `<>` when using the command by reply to a custom emoji.

**Examples:**

- `/help notes` opens the Notes guide.
- `/filter hello Hello, {first}!` saves a reply that uses the sender's first name.
