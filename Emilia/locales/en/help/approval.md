# Approval

Immune trusted members from locks, blocklists, and antiflood.

## User commands

- `/approval [user]`: Check approval status of yourself or a user by reply, mention, username, or ID.

## Admin commands

- `/approve [user] [reason]`: Approve a user.
- `/unapprove [user]`: Remove user approval.
- `/approved`: List all approved members.

## Owner commands

- `/unapproveall`: Remove all approved users. This cannot be undone.

## Example

```
/approve
```
