# Anime

Search anime, manga, characters, and studios.

## User commands

- `/anihelp`: Open anime help menu.
- `/findanime`: Reverse-search image source via SauceNAO.
- `/quote`: Send a random anime quote.
- `/animequotes`: Send an anime quote image.

## Example

```
/anime Frieren
```
