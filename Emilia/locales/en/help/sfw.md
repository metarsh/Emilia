# Anime reactions

Send an anime image or GIF. Reply to a member's message to include them in a caption.

## Images

- `/waifu`
- `/neko`
- `/husbando`
- `/kitsune`

## Example

Reply to a member's message, or send the command by itself:

```
/hug
```
