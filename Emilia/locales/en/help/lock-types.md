# Lock types

Supported content lock types for `/lock` and `/unlock`. Admins and approved users are immune.

## Supported lock types

- `all`: All messages.
- `album`: Photos or documents sent as albums.
- `audio`: Audio media files.
- `bot`: Prevents non-admins from adding bots.
- `button`: Messages containing inline URL buttons.
- `command`: Messages starting with a bot command like `/start`.
- `comment`: Comments from users who have not joined the group.
- `contact`: Shared Telegram contacts.
- `document`: File documents and uncompressed media.
- `email`: Messages containing email addresses.
- `emojigame`: Interactive Telegram dice and emoji games.
- `forward`: Any forwarded message.
- `forwardbot`: Forwards from bots.
- `forwardchannel`: Forwards from channels.
- `forwarduser`: Forwards from users.
- `game`: Telegram Bot API games.
- `gif`: GIF animations.
- `inline`: Messages sent via inline bots like @gif.
- `invitelink`: Telegram group or channel invite links.
- `location`: Shared location messages.
- `phone`: Messages containing phone numbers.
- `photo`: Photo media.
- `poll`: Telegram polls.
- `rtl`: Right-to-left text like Arabic, Persian, or Hebrew.
- `sticker`: All sticker types.
- `text`: Regular text messages and captions.
- `url`: Web URLs and links.
- `video`: Video files.
- `videonote`: Round video notes.
- `voice`: Voice notes.
- `reaction`: Message emoji reactions.
- `outsidereaction`: Reactions from non-group members.
- `guestbot`: Messages sent via Telegram guest bots.
- `emojicustom`: Custom emoji. Trust packs with `/allowlist`.
- `spoiler`: Text with spoiler formatting.
- `format`: Formatted markdown text like bold, italic, or strikethrough.
- `code`: Monospace and code formatting.
