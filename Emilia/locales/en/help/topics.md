# Topics

Manage Telegram forum topics.

## Admin commands

- `/topics`: List open topics with quick action buttons.
- `/newtopic <name>`: Create a new forum topic.
- `/renametopic <name> [| topic_id]`: Rename current topic or specify a topic ID.
- `/opentopic [topic_id]`: Reopen current or specified topic.
- `/closetopic [topic_id]`: Close current or specified topic.
- `/deletetopic [topic_id]`: Delete current or specified topic.

## Example

```
/newtopic Games
/closetopic 123
/opentopic 123
```
