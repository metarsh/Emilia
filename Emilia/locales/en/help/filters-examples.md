# Filter examples

Here are ways to save replies for words, phrases, media, and dice results.

**Examples:**

- Save a text reply using the user's first name:\
  `/filter hello Hello, {first}!`
- Save a reply for a phrase:\
  `/filter "good morning" Good morning, {first}!`
- Save an existing message for a phrase. Reply to the message:\
  `/filter "good morning"`
- Save a photo or sticker. Reply to it:\
  `/filter cat`
- Reply when a dice roll is six:\
  `/filter dice:6 You rolled six!`
- Remove the hello filter:\
  `/stop hello`
- Remove the phrase filter:\
  `/stop "good morning"`

Tap Back, then Formatting, to style your saved replies or add buttons.
