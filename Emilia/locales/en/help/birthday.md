# Birthdays

Save member birthdays using `DD/MM` dates like `25/12`.

## User commands

- `/setbirthday <DD/MM>`: Save your birthday. Run in a group to add a reminder there.
- `/birthday [user]`: View birthday of yourself or another user by reply, username, or ID.
- `/delbirthday`: Delete your birthday.

## Admin commands

- `/addbirthday <user> <DD/MM>`: Save a birthday for another group member.

## Example

```
/setbirthday 25/12
```
