# Files and uploads

I can turn text or media into a shareable link, or help you compress and extract files.

**User commands:**

- `/tgm`: Reply to media to upload it to this bot's file service and get a link.
- `/tgt`: Reply to text to upload it as a text file and get a link.
- `/zip`: Reply to a file to compress it into a ZIP archive.
- `/unzip`: Reply to a ZIP archive to extract its files.

Upload links open the saved content outside Telegram. The ZIP commands instead send files back in the chat.

**Examples:**

- Compress a file. Reply to it:\
  `/zip`
- Extract a ZIP archive. Reply to it:\
  `/unzip`
