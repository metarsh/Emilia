# Files and uploads

Upload media, publish texts to Telegraph, or handle ZIP archives.

## User commands

- `/tgm`: Reply to media to upload and get a Telegraph link.
- `/tgt`: Reply to text to publish to Telegraph.
- `/zip`: Reply to a file to compress it into a ZIP.
- `/unzip`: Reply to a ZIP archive to extract it.

## Example

Reply to a file:

```
/zip
```
