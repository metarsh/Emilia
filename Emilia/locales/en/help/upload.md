# Files and uploads

Upload replied content or work with ZIP archives.

## User commands

- `/tgm`: Reply to media to upload it and receive a link.
- `/tgt`: Reply to text to publish it and receive a link.
- `/zip`: Reply to a file to compress it into a ZIP archive.
- `/unzip`: Reply to a ZIP archive to extract its files.

## Example

Reply to the file to compress:

```
/zip
```
